# Development and bootstrap

A contributor beginning with this repository can establish its identity, boundary, architecture, roadmap, validation, TDE status, and handoff without checking out Forge, Workspace, or Engineering Platform source.

1. Read the root [README](../../README.md) and [architecture](../architecture/README.md).
2. Read [AI-development profile status](AI_DEVELOPMENT_PROFILE_STATUS.md) and the local [Forge Platform development extension](FORGE_PLATFORM_DEVELOPMENT_EXTENSION.md).
3. Run `python3 tests/foundation/test_foundation.py`.
4. Read the [composition catalog release boundary](COMPOSITION_CATALOG_RELEASE.md).
5. Read [TDE integration](TDE_INTEGRATION.md) and [family-migration handoff](../governance/FAMILY_MIGRATION_HANDOFF.md).

The current development-host mismatch is explicitly outside this repository-initialization qualification. No Engineering Platform services, CENTRAL/LEGACY state, authority pointer, freeze, schema, or consumer cutover is part of this repository.
